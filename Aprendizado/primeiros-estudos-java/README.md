# Primeiros estudos em Java

Este repositório reúne alguns dos meus primeiros exercícios de programação em Java.
Os exemplos foram organizados e tiveram pequenos ajustes para facilitar a leitura e a execução.

## Exercícios

- **VariaveisETipos.java** — declaração e exibição de variáveis (`int`, `double`, `float` e `String`).
- **SaudacoesEVariaveis.java** — uso de variáveis e impressão de mensagens no terminal.
- **AreaDoTriangulo.java** — cálculo simples da área de um triângulo.
- **MensagemDaTurma.java** — impressão de uma mensagem no terminal.

## Como executar no VS Code

1. Abra a pasta `primeiros-estudos-java` no VS Code.
2. Verifique se a extensão **Extension Pack for Java** está instalada.
3. Abra um dos arquivos dentro de `src/estudosjava`.
4. Clique em **Run** acima do método `main`.

Cada arquivo tem seu próprio método `main`, então execute um exercício por vez.
